# rad-python-exercicios 🐍

Repositório criado para organizar os exercícios e práticas desenvolvidas durante os estudos de **RAD com Python**.

O objetivo deste projeto é praticar conceitos importantes da linguagem Python, mantendo os códigos separados por tema e com uma estrutura organizada para facilitar a evolução, revisão e manutenção.

</div>

---

## 📌 Sobre o projeto

Este repositório reúne exercícios feitos durante meus estudos de Python, com foco em praticar conteúdos essenciais para o desenvolvimento de aplicações.

A ideia não é apenas resolver os exercícios, mas também melhorar minha organização de código, versionamento com Git e separação dos arquivos por responsabilidade.
